# A) User Manual Procedure

## Setting Up a GitHub Repository and Making a First Commit## Prerequisites

Before starting, make sure you have:

1. A computer connected to the internet.
2. A GitHub account.
3. Git installed on your computer.
4. Visual Studio Code or another text editor.
5. Basic knowledge of opening PowerShell or Command Prompt.
6. A project folder containing at least one file.

## Procedure

### Step 1: Open GitHub

**Action:** Open GitHub in your web browser and sign in to your account.

**Expected result:** Your GitHub account dashboard is displayed.### Step 2: Create a new repository

**Action:** Click the **New repository** button on GitHub.

**Expected result:** The repository creation page opens.### Step 3: Enter the repository name

**Action:** Type a unique name for your project in the **Repository name** field.

**Expected result:** The repository name appears in the field.### Step 4: Set the repository visibility

**Action:** Select either **Public** or **Private** visibility.

**Expected result:** The selected visibility option is enabled.
